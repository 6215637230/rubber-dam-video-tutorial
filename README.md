# Rubber dam video assessment tutorial

This repository accompanies a methodological tutorial on procedural
completeness assessment for rubber dam educational videos.

## Contents

- simulation_example/: the simulated 189-record worked example,
  analysis code and reference outputs.
- real_video_pilot/: observed metadata and AI-assisted evidence
  annotations for 14 unique video identifiers.
- figures/: vector figures supporting the tutorial.

The simulated records and real-video evidence are separate datasets.
The real-video package does not contain completed clinical 0–2
ratings or independent human rating pairs.

Follow the README within each component for reproduction instructions.
Repository-deposition statements in the original component READMEs
describe their status when those packages were first prepared.

Third-party videos and complete transcripts are not redistributed.
